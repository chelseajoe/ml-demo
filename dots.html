Inside the brain

Each small map shows where one neuron fires. A neuron in the first layer can only split the map with one straight line. The layers after it mix those straight lines together, and that’s how the answer gets curves.

This brain has no neurons in the middle, so the answer can only ever be one straight line across the map. Try the Circle puzzle with it, then switch to 4 neurons.

Things to try

  • Pick Circle with Just a straight line. Why does it get stuck? Then give it 4 neurons. Can you spot the straight lines it uses to build the circle?
  • Spiral is the hardest puzzle. Which brain can solve it, and how many steps does it take?
  • Turn on Messy dots. Why can’t it get every practice dot right? Is that a bad thing?
  • Add a few orange dots deep inside blue territory. Does the map bend to grab them? What happens to the test score?
  • Click a few question marks onto the map, then press Start over and train again. Does it give the same answers every time?
The brain is a small neural network written in plain JavaScript and trained right in your browser. Its only inputs are each dot’s left–right and up–down position.
