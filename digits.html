How a computer learns to read handwriting

Nobody writes rules like “a 7 has a line across the top.” Instead we show a computer thousands of examples, let it practice, and then test it. Everything below runs live in your browser.

Look at the examples

Each example is a handwritten-style digit paired with the right answer, called its label. Every image is shrunk to a 28 × 28 grid, the same size used by MNIST, the famous dataset of real handwritten digits.

Loading handwriting styles…

Practice set and test set. 6,000 examples are for practice. Another 1,000 are kept hidden as a test, so we can check whether the model really learned or just memorized the answers.

2

Let it practice

Practice works like flashcards: look at an example, guess, check the label, adjust. The model is a small neural network with about 51,000 settings, which are numbers it can tune. They start out random, so its first guesses are bad. Every practice step it guesses 32 examples, then nudges every setting a tiny bit so those guesses would have been less wrong.

Wrong guess? Teach it.

Tap the digit you meant. It will practice on your drawing plus a few extra examples, the same way it learned everything else.

The practice digits are written in 16 handwriting-style fonts, with random tilts and stroke widths, and generated fresh each time the page loads. The classic version of this experiment uses MNIST: 70,000 digits written by real students and census workers.
